# Repositório Acadêmico


### Descrição
Este repositório foi criado para armazenar, organizar e acompanhar a evolução dos meus estudos, projetos e atividades no curso de **Análise e Desenvolvimento de Sistemas** na **Faculdade**. 

O objetivo principal é manter um histórico centralizado de aprendizado em algoritmos, estrutura de dados, engenharia de software e design de interfaces.

### Estrutura do Repositório
```text
Faculdade/
├── Estrutura de Dados/     # Conceitos de ED, ponteiros e algoritmos em C
│   ├── Alocação Dinâmica/  # Manipulação de memória (malloc, calloc, free)
│   ├── Biblioteca/         # Modularização e inclusão de headers (.h)
│   ├── Matriz/             # Operações com matrizes e arrays multidimensionais
│   ├── Pilha e Fila/       # Implementação de LIFO e FIFO
│   ├── Recursão/           # Funções recursivas (MDC, Fibonacci, etc.)
│   └── Projetos/           # Sistemas completos (Gerenciamento de Produtos e Estoque)
└── IHM/                    # Interação Homem-Máquina e prototipagem
    ├── Atividade_1/        # Projeto: Página de noticias para o IF
    └── Atividade_2/        # Projeto: Página Home do IF
```
### Tecnologias e Linguagens

    C: Implementação de Algoritmos, Estruturas de Dados e Recursão.
    Git & GitHub: Controle de versão e portfólio.
    VS Code: Ambiente de desenvolvimento principal.
